# HomelyBites

HomelyBites is an iOS application built with SwiftUI that connects people through home-cooked meals.

## Features
- Create and manage meals
- Map-based browsing with MapKit
- SwiftUI interface
- MVVM architecture

## Tech stack
Swift, SwiftUI, MapKit, Xcode, Git, Figma

## Running locally
Open `HomelyBites.xcodeproj` in Xcode and run on an iPhone simulator.
